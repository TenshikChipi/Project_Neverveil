# Невервейл — Дом Чудес
Невервейл — это сайт интерактивного пространства желаний «Дом Чудес»
Проект посвящён загадочному месту Невервейл, где человек может произнести своё сокровенное желание и стать частью необычной истории
Сайт выполнен в сказочной стилистике с использованием тёмно-синих, фиолетовых и золотых оттенков, декоративных звёзд, облаков и других элементов
## Ссылка на сайт
https://tenshikchipi.github.io/Project_Neverveil/
## Макет
Макет сайта был разработан в Figma
В проекте реализованы несколько основных секций:
- главная страница;
- блок с шаром желаний;
- описание Дома Чудес;
- блок «Как работает Дом Чудес?»;
- события;
- подвал с контактами
## Технологии
В проекте использовались:
- HTML;
- CSS;
- Flexbox;
- SVG-графика;
- CSS-анимации.
## Что реализовано
На сайте реализована навигация между разными секциями страницы с помощью якорных ссылок
Например, при нажатии на кнопку «Календарь событий» пользователь перемещается к секции с событиями
Также на сайте есть кнопка «Загадать желание», которая ведёт пользователя к блоку событий
Для декоративных элементов используются SVG-изображения, а часть звёзд анимирована средствами CSS
## Анимации
Для звёзд используется CSS-анимация вращения через `@keyframes`
Пример:
```css
@keyframes rotateStar {
    from {
        transform: rotate(0deg);
    }

    to {
        transform: rotate(360deg);
    }
}
```
## Навигация
Переход к нужной части страницы реализован через `id` секции и `href` ссылки.
Пример:
```html
<a href="#events">Календарь событий</a>
```
```html
<div id="events">
    ...
</div>
```
Для плавного перехода используется:

```css
html {
    scroll-behavior: smooth;
}
```
## Работа со слоями
В проекте много элементов, которые накладываются друг на друга: облака, карточки, звёзды, текст и декоративные изображения.
Для управления порядком отображения использовалось свойство `z-index`.
